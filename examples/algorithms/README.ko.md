# 돌아가는 교과서 알고리즘

*[English](README.md) | 한국어*

정보 교과서에 나오는 알고리즘 18개를, 교과서가 인쇄하는 의사코드와 **줄이 1:1 로 맞게**
옮겨 놓은 폴더. 각 파일 맨 위 주석에 그 의사코드가 그대로 들어 있어서 나란히 놓고 읽을 수 있다.

여기는 Venos 가 스스로 한 약속을 검사받는 자리이기도 하다. 이 폴더의 모든 파일은
`tests/run_tests.sh` 가 **세 방식**으로 돌린다 — 인터프리터, 트랜스파일한 C++ 실행 파일,
그리고 `venos topython` 이 낸 파이썬 — 그리고 셋의 출력이 글자까지 같아야 한다.
장난감 케이스가 아니라 이 프로그램들로 검사한다.

## 돌려 보기

```bash
venos selection-sort.my              # 실행
venos topython selection-sort.my     # selection-sort.py — 같은 프로그램의 파이썬 버전
venos build selection-sort.my run    # 네이티브 실행 파일로 컴파일해서 실행
```

설치가 어려우면 [플레이그라운드](https://vpdrla.github.io/Venos/)에 파일 내용을 붙여 넣고
**🐍 Python** 을 눌러도 된다.

## 목록

| 파일 | 알고리즘 | 무엇을 보여 주나 |
|---|---|---|
| `selection-sort.my` | 선택 정렬 | 비교 횟수는 자료와 무관하게 늘 `n(n-1)/2` |
| `insertion-sort.my` | 삽입 정렬 | 이동 횟수는 자료에 따라 다르다 — 거의 정렬된 자료에 강하다 |
| `bubble-sort.my` | 버블 정렬 | 한 바퀴에 한 번도 안 바꿨으면 거기서 멈추기 |
| `merge-sort.my` | 병합 정렬 | 반으로 쪼갠 뒤 **합치기**; 자료가 어떻든 n log n |
| `quick-sort.my` | 퀵 정렬 (Lomuto) | 분할 한 번을 눈으로, 마지막 값을 피벗으로 쓰면 정렬된 자료가 최악인 이유 |
| `linear-search.my` | 순차 탐색 | 최선 1회, 최악 n회, 평균 (n+1)/2회 |
| `binary-search.my` | 이진 탐색 | 범위가 반씩 줄어드는 과정; 100만 개를 20번에 |
| `gcd.my` | 유클리드 호제법 | 반복형·재귀형과 최소공배수, 약수를 다 세는 방법과 비교 |
| `primes.my` | 소수 판별, 에라토스테네스의 체 | 소인수분해, 소수가 점점 드물어지는 모습 |
| `fibonacci.my` | 피보나치 세 가지 | 재귀 vs 반복 vs 메모이제이션 — 호출 횟수로 이유를 보여 준다 |
| `hanoi.my` | 하노이의 탑 | 재귀가 아니면 쓰기 어려운 문제 |
| `base-convert.my` | 진법 변환 | 10진 ↔ 2·8·16진, 양방향 |
| `palindrome.my` | 뒤집기, 회문 | 양 끝에서 좁히기와 뒤집어 비교하기, 가장 긴 회문 |
| `statistics.my` | 평균·중앙값·최빈값·표준편차 | 등급 분포를 막대그래프로 |
| `matrix.my` | 행렬 덧셈·곱셈·전치 | `A×B ≠ B×A` 인 이유 |
| `stack-queue.my` | 스택과 큐 | 리스트로 만들기; 괄호 짝 맞추기, 인쇄 대기열 |
| `caesar-cipher.my` | 시저 암호 | 무차별 대입과 글자 빈도; 음수 나머지가 필요한 예 |
| `run-length.my` | 런길이 압축 | 압축했는데 오히려 커지는 경우 — 그게 요점이다 |

## 읽기 전에 하나만

**리스트 인덱스는 1부터**다. 교과서 의사코드(`A[1]` 이 첫 번째)와 같은 약속이다.
파이썬으로 옮길 때 달라지는 곳은 사실상 여기 하나뿐이고, `topython` 이 알아서 `A[i-1]` 로
바꿔 주며 생성된 파일 머리말에도 그렇게 적어 둔다. 머리말에 같이 적히는 단서 하나 —
파이썬은 음수 번호를 뒤에서부터 세는 뜻으로 읽는다. 번호가 1 아래로 내려가면 Venos 는
에러를 내지만 옮긴 파이썬은 마지막 원소를 조용히 돌려준다. 숫자가 소스에 그대로 적혀 있으면
(`A[0]`) `topython` 이 아예 거절한다.

## 알아 둘 한계 두 가지

`hanoi.my` 는 전설의 64개가 아니라 50개까지만 센다. Venos 의 수는 double 이라 약 9천조까지
정확한데 2^64−1 은 그 너머다. 파이썬 정수에는 한계가 없으니, 수가 아주 커지면
`venos topython` 으로 옮겨서 돌리는 게 진짜 답이 된다.

이 폴더의 파일은 `random()` 과 `time()` 을 쓰지 않는다. 세 방식을 비교하려면 매번 같은 출력이
나와야 하기 때문이다.
