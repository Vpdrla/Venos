# 옮길 수 없으면 거절해야 한다

`topython` 은 "같은 프로그램의 파이썬 버전"을 약속한다. 그래서 **틀린 파이썬을
내는 것이 거절보다 나쁘다** — 학생은 그게 틀렸다는 걸 알 길이 없기 때문이다.

여기 있는 프로그램들은 파이썬이 Venos 와 **다르게 답하는** 자리들이다.
각 `.my` 를 `venos topython` 에 넣었을 때 나와야 하는 출력이 `.expected` 에 있고,
러너가 글자까지 비교한다.

| 파일 | 파이썬이라면 | Venos 는 |
|---|---|---|
| `인덱스_0.my` | `xs[-1]` → 마지막 원소 | 에러 (인덱스는 1부터) |
| `replace_빈문자.my` | 글자 사이마다 끼워 넣어 `-a-b-c-` | 에러 |
| `find_빈문자.my` | `0` (+1 해서 `1`) | 에러 |
| `min_문자열.my` | 사전순으로 비교해 `"a"` | 에러 (수 전용) |

리터럴로 적혀 있지 않은 경우(변수에 빈 문자열이 들어오는 등)는 생성된 파이썬 안의
`_replace`·`_find`·`_substr`·`_idx` 가 같은 규칙으로 막는다. 그쪽 검증은
`tests/cases/py_guards.my` 가 3중 differential 로 한다.
